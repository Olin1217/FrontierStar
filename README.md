# 未来星（FrontierStar）

未来星连接家庭与新兴科技领域的专业人士，帮助儿童和青少年通过行业知识、真实体验和动手项目探索自己的兴趣。平台把这些专业人士称为“前沿引路人”，让可信的专业经验与每个孩子的学习需求建立连接。

## 当前产品范围

- 课程发现：全屏纵向浏览课程和多节项目，查看讲师、适龄范围、周期与安排。
- 前沿引路人：展示教育背景、职业经历、专长、课程、实践项目和真实评价。
- 家长学习需求：提交孩子年龄、兴趣、基础和目标，由平台协助匹配。
- 课程与项目发布：引路人可以发布课程和实践项目。
- 报名与跟进：家长提交报名后由课程顾问联系确认，并在个人页查看状态。
- 游客浏览：未注册用户也可以查看公开课程、项目和引路人内容。

重点方向包括人工智能与大语言模型、机器人、无人机、具身智能和智能硬件。学习体验强调行业知识、真实应用和项目制探索。

## 技术结构

这是一个使用 UIKit 编写的 iOS 原型工程：

- `FrontierStar/`：App 入口、课程流、项目列表、家长需求、个人资料、模型和本地状态。
- `FrontierStar.xcodeproj/`：Xcode 工程。
- `APIClient.swift`：可选的服务端仓储接口；当前 MVP 默认使用本地演示数据。

## 运行

使用 Xcode 打开 `FrontierStar.xcodeproj`，选择 iOS 模拟器或设备后运行 `FrontierStar` Scheme。工程不包含服务端密钥；生产接入应通过 HTTPS 服务端配置认证、匹配和数据存储。

## 产品愿景

让孩子认识、体验并主动探索前沿科技，帮助他们遇见真正理解前沿的人。
